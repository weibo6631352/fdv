# src 目录说明

该目录存放 Python 源码包，采用 `src` layout。这样可以减少测试时误用当前工作目录代码的概率，也让包导入路径与真实安装环境一致。

## 职责

- 存放可发布、可测试、可运行的 Python 源码。
- 保持源码包和测试、文档、迁移脚本分离。
- 作为后续拆分服务或发布包时的根目录。

## 目录边界

- 主包是 [fdv_trader](./fdv_trader/README.md)。
- 这里不放测试代码，测试放在 [tests](../tests/README.md)。
- 这里不放 Alembic 版本脚本，迁移放在 [alembic](../alembic/README.md)。
- 这里不放运行时密钥、`.env` 或生产配置。

## 开发约束

- Python 目标版本为 3.12+。
- 新增模块时优先放入已有分层目录，避免直接在 `fdv_trader` 根目录堆业务代码。
- 模块命名使用英文，用户可见文案和关键业务注释可使用中文。
- 任何交易相关新代码都需要明确属于 P0、P1、P2 或 P3 路径。
